A one-line roast of my own AI agent (118 characters), written by the program to `/output/entry.txt`: it brags it works while I sleep, then pings me at 3 a.m. to approve the one button it was built to click itself. Autonomous in the pitch, approval-gated in practice — the roast lands on the gap between what agents promise and what they actually do.

## Run it

```sh
python3 main.py
```

This writes the roast to `/output/entry.txt` (override the directory with `MAKEFUN_OUTPUT_DIR`). Standard library only; no network, no dependencies.
